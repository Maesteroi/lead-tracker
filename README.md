# lead-tracker

النسخة الأصلية من كود Lead Tracker: منصة بتربط الضغطة بالزيارة والتواصل والنتيجة. الفرع الرئيسي `main` هو المرجع، وأي تعديل بيتعمل على فرع جانبي وطلب دمج.

| الفولدر | إيه | النسخة |
|---|---|---|
| `apps-script/` | مشروع Apps Script (كود الشيت) — 17 ملف | v3.9.0 |
| `plugin/lead-tracker-pro/` | بلجن ووردبريس | 2.9.0 |
| `server/` | **السيرفر الجديد** (Cloudflare Workers + Supabase): استقبال البلجن وتطبيق الموبايل، والمطابقة، والتحليل — التركيب في `server/README.md` | 1.0.0 |
| `auth/` | **خدمة ربط جوجل أدز** (Cloudflare Worker على auth.maestrolt.com). النشر يدوي من Cloudflare (`auth/README.md`) | 1.0.0 |
| `google-ads-script/` | سكريبت جوجل أدز: نفس الكود في كل حساب، وبيسجّل نفسه | v3.0 |
| `android/` | **تطبيق الموبايل** (ط١.٤): المكالمات وتسجيلها، والواتساب كامل من الطرفين — بيتبني على GitHub لوحده (`android/README.md`) | 1.0.0 |
| `templates/` | قوالب (صفحة سياسة الخصوصية وشروط التواصل) | — |
| `kb/` | قاعدة المعرفة (بتتبني تدريجياً): `04-channels/google-ads/` · `06-execution/roadmap.md` | — |
| `tests/` | اختبارات بمحاكي (Node، من غير إنترنت). بتشتغل لوحدها على كل طلب دمج (`.github/workflows/tests.yml`) | — |
| `tools/` | أدوات بناء وفحص (`check-apps-script.js`: كتابة سليمة ومفيش دوال متكررة) | — |

## ملفات Apps Script المهمة
| الملف | شغلته |
|---|---|
| `Code.js` | استقبال أحداث البلجن (`doPost`)، والكتابة في شيت كل موقع، وتليجرام، وفحص الشبكة (ipapi.is)، وطابور الأحداث |
| `ads-bridge.js` | الجسر مع سكريبت جوجل أدز: التسجيل التلقائي (`ads_sync`) وكتابة الضغطات (`ads_clicks`)، وقايمة «نسخ كود جوجل أدز» |
| `click-gap.js` | التحليل اليومي (8 الصبح): فجوة النقرات، والاشتباه لكل كلمة، ومدينة جوجل، و«تقرير النقرات اليومي»، وتقرير تليجرام |
| `upload-conversions.js` · `phase4-*.js` · `oauth.js` | الرفع القديم للتحويلات بالـAPI (`uploadServicesConversions` شغال 4 العصر) — **مستني مراجعة** |
| `telegram-webhook.js` | بوت تليجرام (الربط والفصل) |
| `outcome-buttons.js` | أزرار النتيجة على تنبيه تليجرام (تم · بيفكر · لغى · مش جاد · ماوصلش رسالة) ← عمود «التنفيذ» |
| `server-sync.js` | الشيت ↔ السيرفر: مزامنة المواقع، وكود ربط الموبايل، وموافقات العميل، والمقارنة اليومية |
| `ads-pull.js` | سحب جوجل أدز بالـAPI للشيت (`_SearchTerms` · `_AdsHealth`) + عداد العمليات |
| `connect-menu.js` | قايمة «🔗 ربط جوجل أدز»: نافذة بالمواقع، ولينك الربط الموقّع وجنبه أيقونة نسخ |
| `ads-migrate.js` | `migrateTokensToServer()`: نقل ربط جوجل أدز من `_Tokens` للسيرفر (بيتخزن هناك مشفّر) |

## الإعدادات (Script Properties — مش في الكود)
`TG_TOKEN` · `TG_CHAT_ID` · `TIMEZONE` · `IPAPI_KEY` · `ADS_KEY` · `WEBAPP_URL` (اختياري) · `SITE_<id>` (سجل كل موقع) · `SERVER_URL` · `SERVER_ADMIN_TOKEN`.
**مفيش أي مفتاح أو توكن في المستودع.**

## الشيتات
- **الملف الرئيسي «Lead Tracker Pro — بيانات»:** لوحة التحكم، ودفتر «🌐 المواقع» (منه «حساب جوجل أدز» و«حملات جوجل»، وبيتملوا لوحدهم).
- **ملف لكل موقع «Lead Tracker — اسم الموقع»:** تبويب الزيارات، و«نقرات جوجل»، و«ملخص جوجل اليومي»، و«تقرير النقرات اليومي»، و«📖 ملخص الزوار».

## الاختبارات
```
node tests/test-bridge.js && node tests/test-gap.js && node tests/test-queue.js && node tests/test-outcome.js && node tests/test-server-sync.js && node tests/test-netcheck.js x
cd server && npm test
```
اختبارات بمحاكي للشيتات وجوجل أدز وتليجرام. ودي مش بديل عن الاختبار الحي، فأي نسخة لازم تتجرب على بيانات حقيقية قبل ما تتعتبر شغالة.
