# سكريبت جوجل أدز — جمع الضغطات

`click-collector.js` بيتركّب **جوه كل حساب إعلانات لوحده** (نسخة لكل حساب). بيقرا بس، ومابيغيرش أي حاجة في الحملات.

كل يوم بيكتب ضغطات امبارح في ملف شيت الموقع، في تبويبين:
- **نقرات جوجل:** صف لكل ضغطة.
- **ملخص جوجل اليومي:** صف لكل حملة.

والتحليل (الفجوة والاشتباه والتقرير) بيعمله `apps-script/click-gap.js`.

## التركيب (لكل حساب)
1. في جوجل أدز: **Tools** ← **Bulk actions** ← **Scripts** ← زرار **+** ← **New script**.
2. سمّيه `Lead Tracker — جمع الضغطات`، وامسح الكود اللي فيه والزق `click-collector.js`.
3. في أول الكود، حط رابط ملف شيت الموقع مكان `PASTE_SHEET_URL_HERE`.
4. **Authorize**، بنفس حساب جوجل اللي يقدر يفتح الشيت.
5. **Preview**: في السجل (Logs) لازم تلاقي عدد ضغطات كل يوم، وجنبه «لوحة جوجل: … ضغطة». ومش هيكتب في الشيت.
6. **Run**: ده اللي بيكتب التبويبين.
7. **Frequency** ← **Daily** ← الساعة 3 أو 4 الفجر.

## الاختبار
عدد ضغطات امبارح في «نقرات جوجل» = عدد الضغطات في لوحة جوجل أدز لنفس اليوم (عمود «ضغطات» في «ملخص جوجل اليومي»).
