# تطبيق Maestro LT للأندرويد (ط١.٤ · نسخة 1)

تطبيق صغير على موبايل الشغل. بيبعت للسيرفر:
- **المكالمات:** الرقم، والوقت، والمدة، والنوع (من سجل المكالمات).
- **تسجيل المكالمة:** الملف اللي مسجّل الموبايل نفسه عمله، **لو العميل موافق** (من قايمة الشيت «✍️ موافقات عميل»). لو الموبايل مفيهوش تسجيل، المدة بس.
- **الواتساب كامل من الطرفين:** رسايل الزبون من الإشعارات، والمحادثة كاملة (رسايل الزبون والردود) من الشاشة وهي مفتوحة.

**الخصوصية:** الأرقام الجديدة بس. الجروبات وجهات الاتصال المتسجلة باسم مابيطلعوش من الموبايل. التطبيق مابيبعتش ولا بيضغط أي حاجة في الواتساب، ومابيكلّمش سيرفرات الواتساب.

## الملفات
| الملف | شغلته |
|---|---|
| `MainActivity.kt` | شاشة الربط والصلاحيات خطوة خطوة والحالة |
| `WaNotificationService.kt` | إشعارات الواتساب + متابعة سجل المكالمات |
| `WaScreenService.kt` | قراية المحادثة من الشاشة (الطرفين) |
| `Calls.kt` | سجل المكالمات وملفات التسجيل |
| `SyncWorker.kt` | الإرسال للسيرفر كل شوية + نبض الصحة |
| `Queue.kt` | طابور على الموبايل (مفيش حاجة بتضيع لو النت قطع) |
| `Parse.kt` | الدوال الصافية (ليها اختبارات) |

## البناء
بيتبني على GitHub لوحده مع كل تعديل (`.github/workflows/android.yml`): الاختبارات + ملف APK.
**التحميل:** GitHub ← Actions ← android ← آخر تشغيل ← Artifacts ← `maestro-lt-debug-apk`.
نسخة الطرح (موقّعة بمفتاح على جهاز محمود بس) بعد ما التجربة تنجح.

## التركيب (موبايل التجربة الأول)
1. حمّل الـAPK على الموبايل وافتحه ← «السماح بالتثبيت من المصدر ده».
2. من الشيت: **🔗 Lead Tracker ← 📱 كود ربط موبايل** ← اختار الموقع ← اكتب الكود في التطبيق.
3. التطبيق بيعرض الخطوات (سجل المكالمات · إشعارات الواتساب · قراية المحادثات · البطارية · ملفات التسجيل) — كل واحدة بزرار «فعّل».
4. على أندرويد 13 وأحدث: لو «قراية المحادثات» رمادي ← الإعدادات ← التطبيقات ← Maestro LT ← ⋮ ← «السماح بالإعدادات المقيّدة».

## لازم يتجرب على موبايل حقيقي (ط١.٤ 4.1)
- أسماء العناصر في شاشة الواتساب (`conversation_contact_name` · `message_text` · `date` · `status`) بتتغير مع التحديثات: أول تجربة بتأكدها.
- مكان ملفات التسجيل لكل ماركة (سامسونج · شاومي · غيرهم).
- البطارية على 3 ماركات.
