# سكريبت جوجل أدز: جمع الضغطات (v3، نفس الكود لكل الحسابات، وبيسجّل نفسه)

`click-collector.js` **نفس الكود بالظبط في كل حساب إعلانات**. بيقرا بس، ومابيغيرش أي حاجة في الحملات.

- أول ما يشتغل، بيبعت رقم الحساب وحملاته والرابط اللي كل إعلان بيودّي عليه.
- `apps-script/ads-bridge.js` بيطابق الرابط بعمود «الرابط» في دفتر «🌐 المواقع»، ويكتب «حساب جوجل أدز» و«حملات جوجل» لوحده. والحملات الجديدة بتتضاف لوحدها، وحساب واحد ممكن يغطي أكتر من موقع.
- كل يوم بيبعت ضغطات امبارح، وكود الشيت بيكتبها في ملف الموقع («نقرات جوجل» و«ملخص جوجل اليومي»).
- التحليل `apps-script/click-gap.js` كل يوم الساعة 8 الصبح.

## الاستخدام
1. في الشيت الرئيسي: قايمة **🔗 Lead Tracker** ← **📋 نسخ كود جوجل أدز** ← **نسخ الكود**. الرابط والمفتاح متحطين جواه.
2. في أي حساب جوجل أدز: **الأدوات** ← **الإجراءات المجمّعة** ← **النصوص البرمجية** ← **+** ← لزق ← **تشغيل**.
3. من قايمة النصوص البرمجية: **التكرار** ← **يوميًا** ← الساعة 3 الفجر.

## للمطوّر
- الكود اللي بيظهر في «نسخ كود جوجل أدز» متخزن جوه `apps-script/ads-bridge.js` (`ADS_SCRIPT_SOURCE`): `python3 tools/build-ads-template.py` بعد أي تعديل في `click-collector.js`.
- الاختبارات: `node tests/test-bridge.js` (ومعاها test-gap وtest-queue وtest-netcheck).
