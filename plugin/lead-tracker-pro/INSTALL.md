# 🚀 دليل تركيب Lead Tracker Pro

## ⏱️ الوقت المتوقع: 15 دقيقة

---

## 🎯 المرحلة 1: تجهيز Google Sheet + Apps Script

### 1.1 إنشاء Google Sheet
1. اذهب إلى [sheets.new](https://sheets.new)
2. سمّه: `Lead Tracker Pro — بيانات`
3. احفظ الـ ID من الرابط (الجزء بين `/d/` و `/edit`)

### 1.2 فتح Apps Script
1. من الشيت: **Extensions → Apps Script**
2. احذف الكود الموجود
3. الصق محتوى `apps-script/code.js` كامل
4. احفظ (💾 أو Ctrl+S)
5. سمّي المشروع: `Lead Tracker Pro`

### 1.3 إعداد Script Properties
1. من Apps Script: **⚙ Project Settings**
2. انزل لـ **Script properties**
3. أضف المتغيرات دي:

| Key | Value | مثال |
|---|---|---|
| `SECRET` | اختياري — للمواقع القديمة اللي اتظبطت يدوي بس (الربط الأوتوماتيك بيعمل مفتاح لكل موقع لوحده) | `MySite@2026SuperSecret123` |
| `TG_TOKEN` | توكن البوت من @BotFather | `7891234567:AAH...` |
| `TG_CHAT_ID` | شات ID (أي رقم مبدئيًا) | `0` |
| `TIMEZONE` | اختياري | `Asia/Riyadh` |
| `SITE_LABEL` | اختياري | `اسم موقعك` |
| `TEST_SITE_ID` | اختياري | `test-1234` |

### 1.4 تشغيل testTelegram
1. من Apps Script: اختر `testTelegram` من القائمة
2. اضغط ▶️ Run
3. سيطلب منك صلاحيات → **Review permissions → Advanced → Go to (unsafe) → Allow**
4. اقرأ Execution log:
   - لو `TG_CHAT_ID` = رقم بوت → سيتصحح تلقائيًا
   - لو مش لاقي → ابعت للبوت رسالة ثم شغّل `fixChatId`

### 1.5 تشغيل testSetup
1. اختر `testSetup` → ▶️ Run
2. تحقق من Google Sheet:
   - لازم يظهر شيت **🌐 المواقع** فيه صف تجريبي
   - لازم يظهر شيت **موقعك التجريبي (test-123...)** فيه صف
   - لازم يجيلك إشعار Telegram فيه اسم الموقع أول سطر

### 1.6 نشر Web App
1. من Apps Script: **Deploy → New deployment**
2. اضغط ⚙ (gear) → اختر **Web app**
3. الإعدادات:
   - **Description**: `Lead Tracker Pro v2.3`
   - **Execute as**: `Me`
   - **Who has access**: `Anyone`
4. اضغط **Deploy**
5. **انسخ رابط /exec** بزر النسخ

### 1.7 (اختياري) تفعيل الملخص اليومي
1. اختر `setupDailyTrigger` → ▶️ Run
2. هتجيلك رسالة يومية 9 صباحًا في Telegram

## 🎯 المرحلة 2: تركيب WordPress Plugin

### 2.1 رفع الـ Plugin
**الطريقة 1 (موصى بها):**
1. اضغط فولدر `lead-tracker-pro` كـ ZIP
2. WordPress → **Plugins → Add New → Upload Plugin**
3. اختر الـ ZIP → **Install Now → Activate**

**الطريقة 2 (يدوي):**
1. ارفع الفولدر `lead-tracker-pro` إلى `/wp-content/plugins/`
2. من WordPress → **Plugins → فعّل**

### 2.2 الربط (من 2.3.0 — أوتوماتيك، مفيش حاجة تتعمل)
- بعد «تفعيل» على طول، البلجن بيسجّل نفسه لوحده.
- هتلاقي صف «🟢 مربوط» في **🌐 المواقع** ورسالة تيليجرام «موقع جديد اتربط أوتوماتيك».
- **لو جالك «⏳ موقع جديد مستني تأكيدك»:** يبقى إضافة حماية على الموقع منعت التأكيد. لو ده عميلك، علّم خانة **«موافقة»** قدامه، والبلجن هيكمّل لوحده في خلال ساعة.
- **وقف عميل:** قايمة **🔗 Lead Tracker ← وقف موقع** ← اكتب الـ Site ID. بياناته هتترفض لحد ما تشغّله تاني.
- عنوان الاستقبال متحط جوه البلجن (config.json). **أي تحديث للكود في Apps Script لازم يتنشر على نفس النشر** عشان العنوان مايتغيّرش: Deploy → Manage deployments → ✏️ → Version: New version → Deploy. (لو عملت New deployment هيطلع عنوان جديد، والبلجن هيحتاج إصدار جديد بالعنوان ده.)
- اختياري في Script Properties: `AUTO_PAIR` = `off` (أي موقع جديد يستنى «موافقة») · `SEPARATE_FILES` = `off` (كل المواقع في الملف ده).

### 2.3 اختبار الاتصال
1. من **Dashboard** → اضغط **اختبار Webhook**
2. النتيجة المتوقعة:
   - ✅ `نجح (HTTP 200) — ok`
   - رسالة في Telegram
   - صف جديد في شيت الموقع

## 🎯 المرحلة 3: التحقق النهائي

### 3.1 اختبار من موبايل حقيقي
1. افتح موقعك من موبايل
2. تحرك في الصفحة → لازم تشوف أحداث `scroll_50` / `scroll_90`
3. اضغط زر واتساب:
   - افتح الرسالة → لازم تلاقي `كود #XXXX` في آخرها
   - ابعتها → إشعار Telegram فوري فيه اسم الموقع أول سطر

### 3.2 في Google Sheet
تحقق من:
- شيت **🌐 المواقع** — موقعك ظهر كـ 🟢 نشط
- شيت **موقعك (xxxxx)** — كل الأحداث موجودة
- كل الأعمدة الـ68 اتملت (العشرة الجداد في الآخر)

### 3.3 لو فيه مشكلة
| المشكلة | الحل |
|---|---|
| `sheet OFF` في WordPress | تأكد من Webhook URL |
| `forbidden` في Apps Script | الموقع موقوف، أو لسه مستني «موافقة» |
| «الرد مش مفهوم» في صفحة البلجن | اتأكد إن النشر Who has access = Anyone، وإن آخر نسخة كود منشورة (Deploy → Manage → Edit → New version) |
| Telegram مش يوصل | شغّل `testTelegram` واقرأ الـ log |
| الشيت مش بينشئ | تأكد إن `site_id` بيتبعت |
| البيانات ناقصة | افتح Console في المتصفح، شوف أخطاء JS |

## 📊 هيكل الشيتات

> **زيارة الصفحة = صف واحد.** التمرير والخروج بيحدّثوا نفس الصف (الثواني · السكرول · الماوس) بدل ما يضيفوا صفوف. الضغطات (واتساب/اتصال) صف لكل ضغطة.

- **🌐 المواقع**: صف لكل موقع (الرابط · آخر حدث · عدد الأحداث · الحالة).
- **تبويب لكل موقع**: كل حدث في صف، بـ58 عمود (الحدث · الزر · المصدر · معرّفات الإعلان · الجهاز · الموقع · الموافقة…). أعمدة `gbraid` و`wbraid` وحالة الموافقة في آخر الصف.

## ⚠️ ملاحظات مهمة قبل التشغيل على موقع حي

1. **الكاش (LiteSpeed أو غيره):** استثنِ مسار `/wp-json/lt/v1/` من الكاش، والبلجن بيضيف وسوم منع التأجيل والدمج للسكربت تلقائياً.
2. **ملف `config.json`:** فيه عنوان الاستقبال بس (مش سر). **المفتاح أبداً ما يتكتبش فيه** — الربط بيحطه في قاعدة بيانات الموقع. حماية الملف بتشتغل على Apache وLiteSpeed؛ على nginx لازم تمنع الوصول للملف من إعدادات السيرفر.
3. **كلاود فلير:** بيتعرف أوتوماتيك وقت الربط. لو اتغيّر بعدين، الخانة في الإعدادات.
4. **الموافقة:** البانر **مقفول افتراضياً من 2.2.0** (القرار: سطر في صفحة الخصوصية). لو اتفعّل: الزائر اللي ما وافقش بيتسجل من غير بيانات الجهاز والبصمة والمعرّف الدائم وأول مصدر. لو كنت مفعّله في إصدار قديم، اقفله من الإعدادات (القيمة القديمة محفوظة).
8. **حجم البيانات (2.2.0):** الافتراضي بيسجّل زائر الإعلان بالتفصيل وضغطات التواصل من أي مصدر بس. «تتبع كل الزيارات» بيزوّد الصفوف وحدود جوجل كتير؛ ماتفعّلهوش إلا لموقع زياراته قليلة.
9. **تنبيه كل ضغطة على تيليجرام:** مقفول افتراضياً. لتفعيله: Script property `NOTIFY_CLICKS` = `ads` (ضغطات زوار الإعلان) أو `all`، و`NOTIFY_CLICKS_MAX` = أقصى عدد في اليوم (الافتراضي 10).
10. **النقل لسيرفر بعدين:** اكتب الدومين في «دومين السيرفر» وحط رابط السيرفر في Webhook URL. نفس البيانات بنفس الشكل بتروح للسيرفر.
5. **نسخة واحدة بس** من التتبع على الموقع: لو فيه سنيبت v1.2 قديم، شيله قبل تفعيل البلجن.
6. **خرائط جوجل:** جوجل بتخفي مصدر الزيارة من الخرائط في أغلب الأحيان، فحط في رابط الموقع على ملف النشاط التجاري: `?utm_source=google_maps` وهيتسجل «خرائط جوجل» مصدر مستقل.
7. **مساحة الشيت:** ملف جوجل شيتس حده 10 مليون خلية. الملخص اليومي هيحذّرك لما يوصل 60%؛ ساعتها انقل البيانات القديمة لملف تاني.
