# جوجل أدز: تتبع الضغطات وفجوة النقرات

> آخر مراجعة: 26 أكتوبر 2026. أي معلومة عن الـAPI أو السياسات **تتراجع من التوثيق الرسمي** قبل البناء عليها.

## مسار البيانات
```
حساب جوجل أدز (click-collector.js، كل يوم 3 الفجر)
   │  ads_sync: رقم الحساب + الحملات + دومين الإعلان ──► ads-bridge.js يطابق الدومين بدفتر «🌐 المواقع»
   │  ads_clicks: ضغطات امبارح (click_view) + ملخص الحملات ──► ملف الموقع: «نقرات جوجل» و«ملخص جوجل اليومي»
   ▼
click-gap.js (كل يوم 8 الصبح)
   ├─ مطابقة كل ضغطة بزيارتها بالـgclid ← «وصل للموقع؟»
   ├─ «مدينة جوجل» في صف الزيارة (+ «برّه الاستهداف» حسب target_geo من البلجن)
   ├─ «تقرير النقرات اليومي» في ملف الموقع
   └─ تقرير تليجرام لمحمود (مش للعميل)
```

## حقائق اتأكدنا منها (توثيق رسمي + بيانات حية)
| الحقيقة | المصدر |
|---|---|
| `click_view` لازم فلتر **يوم واحد**، ولحد **90 يوم** لورا، و**الـgclid مش متاح** لحملات تطبيقات التثبيت | توثيق Google Ads API fields v26 (click_view) |
| أي حقل بيتفلتر بيه في WHERE (زي `campaign.id`) **لازم يكون في SELECT** مع click_view، وإلا `EXPECTED_REFERENCED_FIELD_IN_SELECT_CLAUSE` | خطأ حي في حساب الإنجاز |
| `location_of_presence.most_specific` بيرجّع **حي (Neighborhood/District) أو رمز بريدي** في السعودية لجزء كبير من الضغطات، والمدينة ساعات فاضية (بيرجّع المحافظة/المنطقة) | بيانات الإنجاز 22–25 أكتوبر |
| قايمة click_view ناقصة **ضغطة أو اتنين في اليوم** عن لوحة جوجل، وكل الضغطات اللي فيها `URL_CLICKS`. **سبب مرجّح (مااتأكدش):** ضغطات زرار الاتصال في الإعلان (مالهاش gclid) | مقارنة 4 أيام |
| `click_view` بيرجّع **كل** أنواع الضغطات (`segments.click_type`)، مش ضغطات الموقع بس: CALLS (زرار الاتصال) · GET_DIRECTIONS و LOCATION_EXPANSION (إضافة العنوان/ملف جوجل بيزنس) · URL_CLICKS · SITELINKS. الاتصال والخرايط مابيفتحوش الموقع، فمايدخلوش في نسبة الوصول (v3.8.0) | بيانات روضة 24–26 أكتوبر: 53 من 64 ضغطة «ماوصلتش» كانت اتصال/خرايط |
| إضافة العنوان (Location asset) ممكن تبقى **على مستوى الحساب** ومربوطة بملف جوجل بيزنس، فمابتظهرش في إضافات الحملة | حساب روضة: مواد العرض ← الموقع الجغرافي ← المستوى: الحساب |
| `metrics.invalid_clicks` على مستوى الحملة = الوهمية اللي جوجل شالها | Google Ads API |
| Google Ads Scripts: `AdsApp.search(GAQL)` بيشتغل جوه الحساب بس. سكريبت يشوف كذا حساب = حساب مدير (MCC) بس | — |
| الرفع الجديد للتحويلات الأوفلاين بالـAPI اتقفل للمستخدمين الجدد من 15 يونيو 2026 (Data Manager API هو البديل)، وتأثيره على السكريبتات مش واضح | ppc.land + Bulk Upload docs |
