# `claude/` — حالة المشروع (المرجع)

الفولدر ده فيه **الحالة الحية** لمشروع Maestro LT. أي جلسة (تنفيذ أو تخطيط) تبدأ بقراية `STATUS.md` من هنا.

| الملف | إيه |
|---|---|
| `STATUS.md` | إحنا فين دلوقتي · المطلوب من محمود. **أول ملف يتقري في أي جلسة** |
| `decisions.md` | القرارات المحسومة والمفتوحة |
| `gaps.md` | النواقص (G-xx) بخطة وموعد ومسؤول |
| `lessons.md` | الدروس: إيه اللي غلط واتعمل فيه إيه |
| `roadmap.md` | بطاقة كل مرحلة (الهدف · المخرج · البوابة) |
| `sessions/` | برومبتات جلسات التنفيذ (S01–S22) |
| `gates/` | تقارير البوابات والجلسات |
| `clients/` | ملف كل عميل (البريف · التشخيص · خط الأساس) |
| `research/` | أبحاث مرجعية بتحتاجها جلسات التنفيذ |

## القواعد
- **المرجع هنا.** أي نسخة من الملفات دي في مشروع Claude مش مرجع (قرار 10 نوفمبر 2026).
- **المكتبة (`maestro/`: الاستراتيجية والمراحل والقنوات والقوالب) لسه في مشروع Claude**، مش هنا.
- **التحديث بطلب دمج.** الطلب اللي بيلمس `claude/` بس بيتدمج من غير موافقة منفصلة (موافقة دايمة من محمود). أي ملف برّه `claude/` بموافقته.
- **مفيش أسرار:** لا توكنات ولا مفاتيح ولا كلمات سر، ولا Site ID لأي موقع (لحد ما G-01 يتقفل). أسماء العملاء وأرقام حسابات الإعلانات مقبولة طول ما المستودع خاص.
- آخر كل جلسة: `STATUS.md` + `decisions.md` + `lessons.md` + `gaps.md`، وتقرير الجلسة في `gates/`.
