تتبع احترافي لكل زيارة ونقرة اتصال/واتساب — Google Sheet + Telegram.

== Description ==
Lead Tracker Pro يسجّل:
* كل زيارة (page_view)
* التمرير (scroll_50 / scroll_90)
* النقرات (اتصال / واتساب)
* الخروج (exit)

ويحفظها في Google Sheet عبر Apps Script مع إشعارات Telegram.

== Installation ==
1. ارفع مجلد lead-tracker-pro إلى /wp-content/plugins/
2. فعّل الإضافة من قائمة الإضافات
3. اذهب إلى الإعدادات → Lead Tracker Pro
4. الصق Webhook URL و SECRET
